# Ossege Online

Statische, responsive Website für GitHub Pages.

## Struktur

Alle Dateien liegen bewusst direkt im Repository-Hauptverzeichnis, damit die Website mit der aktuellen GitHub-Struktur funktioniert.

- `index.html` – Startseite
- `kontakt-piet.html` – Piet
- `kontakt-emil.html` – Emil
- `impressum.html` – Impressum & Disclaimer
- `datenschutz.html` – Datenschutzerklärung
- `style.css` – komplettes Styling
- `main.js` – Navigation, Animationen, Jahreszahl
- `cropped-baum.png`, `piet.png`, `emil.png` – Bilder

## GitHub Pages

Repository → Settings → Pages → Deploy from a branch → `main` + `/ (root)` → Save.

Wichtig: Alle Dateien müssen direkt im Hauptverzeichnis des Repositories liegen.
